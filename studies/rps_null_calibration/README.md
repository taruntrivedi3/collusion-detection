# Adaptive RPS null calibration (robustness for finding 3)

**Question.** Does the within-state shuffle test stay calibrated when honest players adapt to public
history? **Answer.** Yes, in the tested regimes, provided the recorded state covers what they react to:
3.7–6.2% false alarms at a 5% target. Without the history, 99.9% of games raised a false alarm.
Circular shifts were overly cautious and lost power. Details: [findings](results/INTERPRETATION.md),
[full report](results/REPORT.md).

The study compares within-state shuffling, circular shifts and newly simulated honest games under
known policies. It covers 25 settings, with 25,000 honest evaluation games, 25,000 calibration games,
12,000 coordinated games, 11,000 sensitivity games and 50,000 normalization games.

- [Protocol](PROTOCOL.md), [configuration](config.json), [statistical notes](STATISTICAL_NOTES.md).
- [False alarms](results/source_style_false_alarm.csv), [power](results/power.csv),
  [per-game results](results/per_game.csv).

From the repository root:

```bash
python scripts/reproduce.py rps --output /path/to/new/rps-check              # build + validation
python scripts/reproduce.py rps --mode full --workers 8 --output /path/to/new/rps-run
```

The engine (`code/engine.cpp`) is checked against the shared `collusion/` package by
`code/validate.py`. Raw normalization banks and simulation chunks are regenerated by the full run.
