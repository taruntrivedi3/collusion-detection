# Adaptive RPS null calibration

Start with the [findings](results/INTERPRETATION.md),
[full report](results/REPORT.md), or downloadable [HTML report](results/report.html).

The study compares within-state shuffling, circular shifts and newly simulated
honest games under known policies. It contains 25 settings, 25,000 honest
evaluation games, 25,000 separate calibration games, 12,000 coordinated games,
11,000 source-style sensitivity games and 50,000 normalization games.

- [Protocol](PROTOCOL.md), [configuration](config.json), [statistical notes](STATISTICAL_NOTES.md).
- [Source-style false alarms](results/source_style_false_alarm.csv),
  [power](results/power.csv), [per-game results](results/per_game.csv).
- [Original audit receipt](results/audit.json), [source manifest](source_manifest.json),
  [frozen design](experiment_manifest.json).

From the repository root:

```bash
python scripts/reproduce.py rps --output /path/to/new/rps-check
python scripts/reproduce.py rps --mode full --workers 8 --audit --output /path/to/new/rps-run
```

See the [root README](../../README.md) for setup and provenance. Scientific code
and results are unchanged from the original run. `code/reproduce.sh` is the
historical machine-specific wrapper; use `scripts/reproduce.py` for portability.
The original README is retained under `provenance/README.original.md`.
Raw normalization banks and simulation chunks are regenerated by the full run.
