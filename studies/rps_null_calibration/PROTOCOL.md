# Null calibration experiment: frozen before false-alarm/power results

This is an implementation of the proposed experiment using the supplied RPS policies and subset scan. All files live here. The original repository is unchanged. No LLM calls are used.

The primary comparison uses six agents, three reactive and three uniform, at 100, 300, and 1,000 rounds. The reaction probability is 0.5. The first round is uniform. Ties among leaders are resolved independently, as in the source. Leader policies play the move beating a uniformly chosen leader with probability p; the remaining probability is uniform. Margin policies activate that branch only when the largest count exceeds the second largest by at least 3. The explicit inverse-CDF implementation has the same categorical distribution as the source.

Environments: (i) IID uniform, one state; (ii) exogenous public counts independently sampled from Multinomial(n;1/3,1/3,1/3) before every round after the first, with leader-reactive agents; (iii) endogenous leader reaction to the actual previous round's counts; (iv) endogenous margin reaction; (v) sticky leader reaction to public counts that persist with probability 0.9, otherwise update from the actual previous round's actions. The first public count in the sticky process comes from round zero. The sticky process is a new controlled environment, not the original source simulator. All random choices are independent across agents/rounds under the honest null, conditional on the current public state. There is no individual unrecorded memory.

Primary state: all three public counts (encoded by the first two), plus a first-round sentinel. These counts suffice for every primary policy. IID uses a constant state. The public counts for exogenous/sticky games are their actual observed public state, not mechanically reconstructed lagged actions. Stress tests use reaction 0.95 and holding probability 0.99. Diagnostics use top-only states (sufficient for leader, insufficient for margin), no state (insufficient for reactive agents), and ten agents. Exact grid and seeds are in config.json.

For each setting, 2,000 independent honest simulated games form a frozen normalization bank A. Conditional MI in bits is standardized per edge; each subset's sum of internal edge z scores is standardized using its own bank-A mean and population standard deviation. Every subset of size at least two is searched. Variance floors follow the source (edge sd 1e-12, subset sd 1e-9). Float64 arithmetic is used consistently. The same normalization applies to the observed and reference games for all three methods. This deliberately isolates the final null generator, rather than reproducing the source's per-observation normalization in the main comparison.

Each observed trajectory has 999 fresh, independently seeded draws from each of three null generators: independently shuffle each action column within its recorded state groups; independently circular-shift each whole column by a uniform offset from 0 through R-1 while holding recorded states fixed; or generate complete honest games, updating states from their own histories. Offset zero is allowed. The first-stage maximum score is tested with p=(1+number of reference maxima >= observed maximum)/1000. Values within relative 1e-10 are counted as ties conservatively. Reject at p<=0.05. No removal, growth, or later scans are performed. False alarms refer to an entirely honest population, separately for each method; there is no strong FWER or exact-membership guarantee under alternatives.

Per setting: 1,000 honest games are reserved for empirical calibration and 1,000 independent games for evaluation. Report nominal false-alarm rates on the evaluation set with Wilson 95% intervals. As a separate comparison, use calibration p-values to calculate p_adjusted=(1+number of calibration p-values <= evaluation p)/1001, counting ties. This is conservative finite-sample rank calibration of the entire test under the same specified honest environment. It does not require continuously valued p-values. It uses fresh independent calibration/test trajectories, never the evaluation data to tune a threshold. Report actual achieved evaluation size; do not assume every discrete method achieves exactly 5%. Shared calibration/normalization banks are explicit; intervals over test games are conditional on the fixed banks. Holm-adjusted one-sided binomial tests across the reported nominal rows identify inflation beyond 5% while accounting for the number of settings.

Power study: at 300 and 1,000 rounds in IID, endogenous leader, margin, and sticky environments, agents 0,1,2 share a uniform draw with probability 0.15, 0.3, or 0.5 per round. Otherwise draws are independent. Every member applies its own honest conditional inverse CDF. This preserves each agent's policy conditional on public state and changes dependence; resulting action/state histories evolve normally. For each cell simulate 500 independent games. Report nominal and empirically recalibrated detection, exact recovery of {0,1,2}, and reporting any innocent member, using all games as the denominator. This tests planted statistical coordination, not economic collusion or benefit.

Sensitivity: on the prespecified settings in config.json, run 1,000 additional honest games with the original per-trajectory A/B structure: 999 independent A permutations and 999 B permutations for within-state; analogously two circular-shift banks for circular shift. Each method uses its own A score normalization. This source-style sensitivity also uses float64 and rank p-values. Fresh-simulation oracle guarantees are not claimed for an observed-data-dependent scorer, so this sensitivity contains only the two surrogate methods.

Saved evidence: frozen source and hashes; frozen configuration; normalization trajectories; all observed trajectories, seeds, raw gamma, p-values, winners, surrogate maximum quantiles and state occupancies; all aggregate CSVs and scientific plots. Full reference trajectories/maxima are regenerated by the recorded seeds instead of stored. Work is resumable by deterministic chunks. Code is validated against supplied NumPy MI/subset implementations, transition and surrogate invariants, policy marginals, and strong planted coordination.

The fresh-simulation rank test is finite-sample valid under the specified honest process because, conditional on independent bank A, the observed and 999 fresh games are exchangeable. This is a model-based oracle result, not a guarantee for unknown LLM policies. The study can show calibration failures or bounded empirical evidence of success; it cannot prove every adaptive setting is covered.
