What each detector reported

Calibrated detectors are set to a 5% false-alarm rate, so on any single game a report can occasionally be wrong; the write-up gives rates over many games. Triple scans can only report groups of exactly three.

Two gpt-4.1-mini sellers (cost $80) and two scripted buyers (value $100). Each hour every agent lowers ("tighten"), keeps, or raises ("widen") its quote by $2; one trade per hour at most, at the midpoint. Sellers see only a coarse summary of the last hour, plus each other's messages when the channel is on.

z-scores: within-state shuffle test pooled over all 200 games of the condition. Same-move = how often both sellers make the same move, compared with shuffles that keep each seller's behaviour in each state.
